No Mac e no Windows, o app pede ao sistema para não aparecer na captura. No Linux, essa proteção não é padronizada e a faixa pode aparecer na gravação. Os aplicativos ainda não têm assinatura comercial; se o sistema avisar, confira que o download veio deste repositório público.
