Escolha seu sistema

O botão inicia o download direto. Depois, siga os passos do seu computador.

Mac

Aplicativo nativo para Apple Silicon e Intel.

Baixar para Mac
  1. Abra o arquivo .dmg baixado.
  2. Arraste Teleprompter para Aplicativos.
  3. Se houver bloqueio, clique com o botão direito no app e escolha Abrir.

Windows

Um arquivo EXE para Windows 10 ou mais recente.

Baixar para Windows
  1. Abra o arquivo .exe baixado.
  2. Se aparecer um aviso, clique em Mais informações.
  3. Confira o nome do arquivo e escolha Executar assim mesmo.

Linux

Arquivo portátil para desktop Linux x86-64.

Baixar para Linux
  1. Extraia o arquivo .tar.gz.
  2. Nas propriedades, permita executar o arquivo como programa.
  3. Abra GhostTeleprompter-Linux-x86_64.
Sobre a gravação

No Mac e no Windows, o aplicativo usa a proteção de captura oferecida pelo sistema. A versão Windows é construída e aberta automaticamente em um runner Windows a cada atualização. Como gravadores podem usar métodos diferentes, faça uma gravação de cinco segundos antes do primeiro uso importante. No Linux, a faixa pode aparecer na captura.
